Omarchy Cursor

Test area. Hover a tile to see that cursor on your real pointer.

Install from GitHub
omarchy pkg add xorg-xcursorgen && git clone https://github.com/FarzadHayat/omarchy-cursor.git ~/.local/share/omarchy-cursor && ~/.local/share/omarchy-cursor/install.sh

Theme

Pick your colors.toml or drop it on the page. It never leaves your computer. Find it in ~/.config/omarchy/themes/ or ~/.local/state/omarchy/current/theme/.

Background

Needs a mouse or trackpad. Made for Omarchy. Source on GitHub.
